# スマートフォン実機の確認手順

このファイルは受け入れテストの手順です。現在の開発環境で実施済みという意味ではありません。

## 対象

少なくともiPhone Safari、iPad Safari、Android Chromeを各1台。OS・ブラウザ版・機種・URL・照明・壁素材を記録します。HTTPSで配信し、カメラとモーションの権限を有効にします。SNS内ブラウザでは外部ブラウザへの案内を確認します。

## 手順と期待する結果

1. 初回読み込み：作品6点とプレビューが表示され、カメラ許可はまだ要求されない。
2. AR開始：AndroidはWebXR対応確認、iOSは8th Wallエンジンの読込後、「カメラを開始」の操作で権限を求める。拒否すると原因が表示され、カメラを停止してプレビューに戻れる。
3. 壁認識：特徴のある壁を上下・左右に動かして映す。3回の検出一致後に壁の向きごとに色分けされた面・輪郭・格子が表示され、配置可能になる。デバッグOFFでも見えること。床だけを映した場合は配置できない。
4. 額装姿勢：正面・斜めから確認し、絵が壁と平行で、額縁の厚みが室内側に出ることを確認。
5. 表示サイズ：額装外寸62 × 82cmの初期作品を、壁に貼った同寸の目印と比較。壁から1m・2m・3mでそれぞれ認識をやり直し、補正なしの幅・高さの誤差を記録。手動補正の操作は表示されない。
6. 移動：作品の四隅と「つかんで移動」の案内を確認。同じ壁をドラッグすると壁色が濃くなり、指を離すと薄く戻る。移動中の端末回転や指の追加で操作が固まらない。隅でも額縁全体が認識済み範囲内に収まること。
7. 作品変更：壁端の近くで大きい作品へ変更。必要なだけ位置が補正され、作品サイズが勝手に縮まらない。入らない場合は元の作品のまま理由を表示。
8. 隣接壁：二面を十分に認識させ、角付近と別の壁へ移動。新しい壁の向きに揃い、認識済みの隣接壁を突き抜けない。
9. 操作整理：下部の操作は「作品を切り替え」「別の壁に飾る」の2つ。「壁の範囲」「実寸補正」が表示されない。「別の壁に飾る」で古い作品・壁の表示が消え、再認識できる。
10. 追跡喪失：レンズを一時的に覆う。作品と色のついた面が隠れ、ドラッグが終了して操作が停止。壁のデータは保持され、追跡の復帰後に再表示されること。復帰した際のずれを記録。
11. 中断：別タブ・ホーム画面へ移動し、カメラインジケーターが消える。復帰後はプレビューから再開始できる。
12. 画面回転：縦横を切り替え、カメラの比率・タップ位置・操作UIが合うこと。
13. QR：別端末で公開URLのQRを読み取り、対象の作品だけを表示。不明なIDでは他の作品にフォールバックしない。
14. 公開更新：管理編集 → JSON書き出し → public/catalog.json差し替え → デプロイ後、別端末のゲストに更新が反映。
15. デバッグ：AR右上「デバッグ」をON。水色の点群、黄色の候補、向きごとに色分けされた認識済み壁、配置中の壁の白枠を確認。カメラを動かしても壁に重なること。OFFにすると点群と診断パネルが消え、通常の色のついた壁表示は残る。
16. 失敗の切り分け：無地の壁と貼り紙がある壁で受信点・対象点・面内点・候補寸法を比較。「診断をコピー」のJSONを記録。追跡喪失中は3Dデバッグを隠し、LIMITEDと表示すること。
17. 壁の保持：作品を置く前に色のついた壁を認識させ、端末を反対へ向けて30秒待ってから戻す。壁数と認識済みの形が維持され、3回の再認識を待たずに配置できること。壁の一部だけを映しても元の範囲が縮まないこと。作品配置後も同様に確認する。

18. 重複面：同じ壁を正面・斜めから繰り返し映し、奥行きが少し違う面が重なって増えないこと。配置後も同じ位置をタップして、作品が手前の別面へ飛ばないこと。重複が発生した場合は端末情報と診断JSONを記録。
19. 角の色：直交する二面を認識し、面・輪郭・格子の色が違うことを確認。カメラ外から戻る、ドラッグする、作品を切り替える、デバッグをON/OFFする操作でも色の対応が維持されること。離れた平行面は別の壁として残ること。

## Android WebXRの追加確認

- `?debug=1` で開き、AR DEBUGが「WebXR」と表示される。Androidでは8th WallのCDNリクエストが発生しない。
- Depth対応端末では「Depth：取得中」と「点群：深度」を確認。取得待ちの場合は端末を少し移動する。
- Depth非対応端末ではAR自体が起動でき、「点群：ヒットテスト」になる。面検出がない場合は壁の上下・左右を映して点群の範囲を広げる。床へのヒットだけでは壁を作らない。
- カメラの背景が透明な操作画面越しに見え、黒い画面や部屋プレビューで覆われていない。作品選択、タップ、ドラッグ、終了ボタンが使える。
- 縦横回転後もタップ位置と壁が一致する。作品切替中・画面回転中も実寸を維持する。
- 権限拒否後、案内が表示され再試行できる。権限待ち中に終了した場合、遅れて開始したセッションがカメラを保持しない。
- ChromeのAR終了操作、アプリ内の終了、ホーム画面へ移動でプレビューに戻り、カメラが終了する。
- WebXR非対応端末・アプリ内ブラウザではChrome / ARCoreの案内を表示。8th Wallへ自動で戻さない。
- iPhoneとiPadのSafariでは「8th Wall · 空間特徴点」と表示され、従来の操作ができる。App Clipへの遷移は発生しない。
