ArtAR プライバシーポリシー

最終更新：2026年10月13日　運営者：Jun Tachikawa（個人事業主）

要点

  • カメラ映像や写真を ArtAR のサーバーへ送信しません。壁の認識も写真の作成も、お使いの端末の中で行います。
  • アートの閲覧や AR にログインは不要です。閲覧者の氏名・メールアドレス・位置情報・広告識別子は扱いません。
  • サービス改善のため、閲覧者を特定しない利用状況（ページ表示、AR の事前対応判定、開始や壁の検出など）を記録します。モバイルWeb版（iPhone / iPadを除く）では、ブラウザが提供する場合に限り機種名も記録します。iOSアプリ・App Clip・iPhone / iPadのブラウザでは機種名を記録しません。記録は運営者が記録を有効にしている場合だけ行い、広告やトラッキングには使いません。

対象

本書は、Web 版 ArtAR（https://artar-orthogonalinteractive.com/ とその配下）、管理アプリ（/admin/）、iOS 版 ArtAR（親アプリ）と ArtAR App Clip に適用されます。内容は現行の実装に基づいています。

公開ページと AR で扱う情報

端末の中だけで処理するもの

  • カメラ映像：壁の認識とアートの表示のために、ブラウザまたはアプリの中で処理します。iOS の親アプリと App Clip では ARKit が処理し、カメラ映像そのものは Web 側へ渡しません。「写真」で合成した画像だけを、画面での確認と保存のために Web 側へ渡します。
  • AR の写真：「写真」を押したときだけ、カメラ映像とアートにギャラリー名・アーティスト名・アート名・寸法を加えた画像を端末内で作ります。販売中で購入ページが設定されたアートに限り、購入ページを開く QR を加えます。合成した画像は画面で確認してから保存または共有でき、保存先は端末だけです（ブラウザでは共有シートまたはダウンロード、iOS の親アプリでは写真ライブラリ、App Clip では共有シート）。
  • 権限：カメラの許可は AR の開始時に求めます。iOS の親アプリでは写真を初めて保存するときに写真ライブラリへの「追加のみ」の許可を求め、ライブラリの読み取りは行いません。App Clip は写真ライブラリを使えないため、合成した画像を共有シート（AirDrop など）で渡します。WebXR対応ブラウザでは写真のためにカメラアクセスを任意で求めることがあります。位置情報と通知の許可は求めません。

利用状況の記録

運営者が記録を有効にしている場合だけ、閲覧者を特定しない利用状況を Supabase に記録します。

  • 記録する内容：ページの表示、AR の事前対応判定、開始・開始できなかった理由（決められたコードのみ）・壁の検出・アートの配置・追跡の喪失・写真の保存・終了と所要時間、販売中のアートの購入ページを開いたこと、AR で表示したアート。あわせて、表示したギャラリーとアートの ID、OS とブラウザの種類とメジャーバージョン、端末区分、モバイルWeb版（iPhone / iPadを除く）でブラウザが提供する場合の機種名、画面の大きさの区分、主言語、実行環境（ブラウザ・iOS アプリ）、AR の方式を記録します。事前判定はカメラを起動せず、権限も要求しません。AR を開始できる保証ではありません。
  • 記録しない内容：カメラ映像や写真、空間の形状や深度情報、位置情報、端末固有 ID、氏名やメールアドレス、広告識別子や Cookie などの端末をまたぐ識別子、自由入力のエラーメッセージ、購入ページでの購入の有無や購入者の情報。IP アドレスと User-Agent は通信時に Supabase に届きますが、ArtAR のデータベースには保存しません。
  • 識別子：ページを読み込むたびに作る乱数（セッション ID）でイベントをまとめます。端末には保存せず、再読み込みや別の訪問では別の値になります。
  • 閲覧できる人：運営者は全体の集計を閲覧できます。アーティストは自分のアートの購入クリック数と過去90日間のアート表示回数だけを閲覧でき、個々のイベントや他のアーティストの集計は閲覧できません。第三者には提供しません。
  • 保存期間：利用状況イベントは保存期間（90日）を過ぎたものを運営者が定期的に削除します。AR で表示したアートの記録（アート表示イベントの生データは削除せず、期限を設けず保存します）は例外で、アート表示回数は過去90日間の異なるページ読み込み数として数えます。

記録に失敗しても、ページや AR の利用には影響しません。

接続先の事業者

ページの表示や AR の実行に必要な範囲で、次の事業者のサーバーへ接続します。接続先には IP アドレス・User-Agent などの接続情報が渡り、それぞれのプライバシーポリシーに従って扱われます。

接続先用途経路
GitHub Pages（GitHub, Inc.）HTML・JavaScript の配信すべて
Supabase（Supabase, Inc.）アート・アーティスト・ギャラリーの公開情報とアート画像の配信、利用状況の記録、アーティストのアカウントすべて
Google Fonts（Google LLC）書体の取得。接続できない場合はシステムフォントを使用すべて
jsDelivr8th Wall エンジンの取得iPhone / iPad のブラウザ
8th Wall（Niantic）ブラウザ内でのカメラ映像の処理。エンジンから外部へ情報が送信されるかは未確認iPhone / iPad のブラウザ
AppleApp Clip の配布・起動iPhone / iPad の App Clip

WebXRを使用するブラウザと iOS の親アプリ・App Clip（ARKit）では 8th Wall エンジンを読み込みません。

アーティストのアカウント

アートを登録するアーティスト（招待制）について、ログイン用のメールアドレスとパスワード（ハッシュ化して保存）、表示名・紹介文・HP/SNS リンク、登録したアート（画像を含む）・アートセット・共有・ギャラリーを Supabase に保存します。ギャラリーには任意で店舗名・店舗紹介・所在地・公式サイト URL・営業時間を登録できます。公開設定中のギャラリーと活動中のアーティストの公開情報は、誰でも閲覧できます。

  • 退会：アーティストは管理アプリの「アカウント」画面からいつでも退会できます。退会するとアートと画像、アートセット、共有、ギャラリー、アーティスト情報、ログイン用アカウントとメールアドレスを削除し、元に戻せません。ギャラリーの URL と QR は無効になります。端末に保存済みの写真は端末に残ります。
  • 操作の記録：不正な変更や誤操作を調べるため、管理アプリでの編集（日時、操作したアカウントの ID と役割、操作の種類と対象、変更した項目の変更前後の値）を記録します。メールアドレス、パスワード、画像そのもの、閲覧の記録は含めません。閲覧できるのは運営者だけで、記録は追記のみです。1年を過ぎた記録は運営者が定期的に削除します。退会したアーティストの表示名・紹介文・HP/SNS リンクは記録から削除し、「退会済みのアーティスト」と表示します。
  • メール送信手段を設定するまでは、退会完了などの通知メールを送りません。

ギャラリーの URL と QR

ギャラリーの URL（/{galleryId}）と QR は、表示するアートを絞り込むためのものです。URL を知っている人は誰でも同じ内容を見られるため、非公開情報の保護には使えません。アートやアーティストの HP/SNS リンクは外部サイトを新しいタブで開き、リンク先の取扱いはそのサイトのポリシーに従います。
